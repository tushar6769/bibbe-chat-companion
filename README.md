# 🕊️ FaithCompanion - Daily Devotional & AI Bible Chat App

FaithCompanion is a full-stack, mobile-responsive spiritual application designed to help users build a consistent, meaningful habit of scripture study and daily prayer. Powered by the Google AI Studio Gemini API, the app features an intuitive theological AI chat engine, an interactive daily reflection dashboard, and custom user habit tracking.

## ✨ Key Features

*   **AI Bible Chat:** Ask deep theological questions or request historical and cultural context for complex scripture verses.
*   **Daily Devotionals:** A fresh, automated daily dashboard featuring scripture readings paired with AI-generated reflection prompts.
*   **Private Prayer Journal:** A clean, digital space to log personal thoughts, tracking your spiritual growth over time.
*   **Habit & Streak Tracker:** Visual analytics helping users stick to their reading plans and celebrate daily streaks.
*   **Community Prayer Wall:** A module for users to post anonymous intentions and offer supportive community encouragement.

## 🛠️ Tech Stack

*   **Frontend:** Vite, React, TypeScript, Tailwind CSS
*   **Backend:** Node.js, Express, TypeScript
*   **AI Engine:** Google AI Studio (Gemini 1.5 API Integration)
*   **Data Analytics Layout:** Power BI structured layouts for user engagement tracking
